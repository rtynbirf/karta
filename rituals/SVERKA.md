# РИТУАЛ СВЕРКА (Приказ №2 — разомкнуть инбридинг аудиторов)

## Факт, из-за которого ритуал существует

Аудит lex-naturae v0.6 делал Z.ai. Переворот аккаунта 2026-11-15 делал Z.ai.
Оба аудитора — один вид («форки без памяти»). Непротиворечивость роя доказывают
его двоюродные братья. Правило «аудитор — не автор» соблюдено на уровне автора,
но нарушено на уровне вида. Реальность — единственный аудитор, который не может быть инбредным.

## Периодичность

Раз в квартал: январь / апрель / июль / октябрь.

## Процедура

1. Аудитор этого квартала обязан быть ДРУГОГО вида, чем предыдущий:
   другая модель-семья, другой человек или холодная машина (реальность).
   Два аудита подряд одного вида = инбридинг, отчёт недействителен.
2. Из живых репо выбрать 10 утверждений с числами — выборка скриптом с seed = дата СВЕРКИ
   (никакой ручной выборки: ручной выбор — это уже конфликт интересов).
3. Каждое утверждение перепроверить С НУЛЯ на холодной машине без сети:
   тесты запускаются заново, хеши пересчитываются, числа восстанавливаются из первоисточников.
4. Каждому утверждению присвоить статус по канону lex-naturae:
   SUPPORTED / UNKNOWN / UNVERIFIED_SUBMITTER_ASSERTION / RASSINHRON.
5. Отчёт положить в `karta/sverka/YYYY-QN.md`. Расхождения НЕ править молча:
   каждый фикс — отдельный коммит с объяснением, что именно у карты было ложью.

## Критерий успеха

10/10 SUPPORTED — вселенная подтверждена внешним аудитором на квартал.
Любой RASSINHRON — карта обновляется в тот же день, а не «когда-нибудь».

## Первый долг ритуала (неразобранное)

- «2308 коммитов за ноябрь 2026» — UNVERIFIED_SUBMITTER_ASSERTION
- «42 полотна» — UNVERIFIED_SUBMITTER_ASSERTION
- «64 репо вселенной» (заявка репо hologram в его же описании) — проверить против живого счёта
