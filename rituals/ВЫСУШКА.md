# РИТУАЛ ВЫСУШКА (Приказ №8 — резерв не существует, пока не доказано восстановление)

## Факт, из-за которого ритуал существует

Мир: `git clone --mirror` не тянет LFS-бинарники — у voice-atlas-llm в холоде
лежат указатели без объектов (дыра, честно зафиксированная сменой 16.11).
Мир: правило 3-2-1 — три копии, два носителя, один офсайт; у вселенной пока
одна холодная копия (/mnt/cold) + витрина вендора. Мир: «бэкап, который ни разу
не восстанавливали, — это не бэкап, а надежда». Надежды — не по канону Evidence.

## Периодичность

Раз в квартал — в один день с НОЧЬ-БЕЗ-СЕТИ (Приказ №5): сеть рубится,
рой живёт офлайн, зеркало проверяется на холодной машине. Один день — две
проверки автономии.

## Процедура

1. Скриптом с seed = дата ВЫСУШКИ (никакой ручной выборки) выбрать **10 зеркал**
   из _MANIFEST.txt.
2. На чистой машине (не на машине зеркала!) `git clone` из холода — полная
   сборка, не fetch.
3. Сверить HEAD каждого клона с sha256-подписью манифеста.
4. Прогнать тесты lex-naturae из поднятого клона (70/70 — норма).
5. LFS-репо: проверить наличие объектов (`git lfs ls-files` + хранилище lfs-core),
   не только указателей.
6. Отчёт `karta/vysushka/YYYY-QN.md` с двумя сырыми числами:
   поднято / не поднялось. Метрика без сырых чисел недействительна.

## Критерий автономии

ВЫСУШКА идёт без сети. Если зеркало не поднимается офлайн — «офлайн живёт»
лозунг, а не факт, и это записывается с хешем. Смерть, записанная с хешем,
— тоже доказательство.
