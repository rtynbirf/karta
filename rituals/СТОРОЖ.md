# РИТУАЛ СТОРОЖ (Приказ №7 — взаимный пульс роя)

## Факт, из-за которого ритуал существует

Крон index умирал молча **дважды** за трое суток: 11 ч 17 м (16.11) и
16 ч 31 м (19.11). Хаб, поставленный лечить витринные числа от устаревания,
устаревает сам и молчит. Мир знает болезнь: GitHub не алертит падение
schedule-воркфлоу, задерживает ночные прогоны джиттером, отключает расписания
после 60 дней без коммитов, а «успех» с нулём записей выглядит как успех.
Мир лечит внешним SaaS-пингером. Рой — другим способом.

## Периодичность

Ежечасно (СТОРОЖ в karta), еженощно (перегенерация карты 03:21 UTC),
плюс каждая СВЕРКА перепроверяет пороги.

## Процедура

1. **Взаимный пульс:** СТОРОЖ-workflow в karta ежечасно меряет возраст штампов
   STATUS.md (index) и README (karta). Порог index — 3 ч (три пропущенных тика),
   порог karta — 26 ч (сутки + джиттер). Ноль сторонних виджетов — пульс держат
   органы друг друга.
2. **Тревога = витрина.** Тишина старше порога сама становится строкой в
   `CRITIC-alarm.md` карты. Молчание — это тоже число, и оно обязано светиться.
3. **Ноль подозрителен.** Любой генератор обязан доказать ненулевость: выход 0
   при нуле записей = поломка, а не успех. КРИТИК встроен в ночную перегенерацию.
4. **Дыра круга — честно.** Если умрёт сам Actions, сторож умрёт молча вместе с
   ним: изнутри роя собственная смерть невидима. Внешние свидетели: нативные
   письма GitHub о падениях, ВЫСУШКА (холодная машина без сети, Приказ №8),
   и взгляд Хозяина. Круг не выдаёт себя за абсолют.
5. **Орган обязан дышать, музей не обязан.** 60-дневное отключение расписаний
   касается только живых органов (index, karta). Окаменелости покоятся — их
   пульс не нужен, их пломбы не стареют.

## Тест сирены (обязательный первый прогон)

Сирена, ни разу не сработавшая в тесте, не проверена. Первый прогон СТОРОЖА
должен **поймать реальную тишину** index — на момент установки 19.11 штамп
STATUS.md мёртв уже 17+ часов, тревога обязана загореться с первого раза.
Позитивный тест тревоги важнее позитивного теста тишины.

## Критерий успеха

Тишина старше порога невозможна молча: любой мёртвый штамп сам становится
строкой на витрине в течение часа после своего третьего пропущенного тика.
