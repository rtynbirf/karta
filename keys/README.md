# РЕЕСТР КЛЮЧЕЙ вселенной rtynbirf — Приказ №6 ФИТИЛЬ (2026-11-19)

Правила реестра:

1. Ключ — сменный пропуск, не паспорт: fine-grained, read-only, дата смерти ≤ 90 дней.
2. Ключ вне реестра = нелегал: кремируется при обнаружении, без разбирательств.
3. Публичное появление ключа (чат, артефакт, код) = кремация немедленно:
   Settings → Developer settings → Personal access tokens → Delete, затем
   audit_log на чужие вызовы между публикацией и отзывом.
4. В реестр пишется только префикс-шрам (первые 8 символов) — сигнатура детекции,
   не секрет: авторизоваться им нельзя, опознать возвращение трупа можно.
5. Новый аудит/смена => дописать строки ЗДЕСЬ; логика не трогается.
