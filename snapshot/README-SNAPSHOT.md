# SNAPSHOT · карта = артефакт сборки (волна ВОЛЕВОЕ-РЕШЕНИЕ, пункты 1+2+4)

Правило района: «руками счётчик — запрещён». Все числа в СЧЁТЧИКИ.md и
СТАТУС.md рендерятся из snapshot.json, а snapshot.json собирает
tools/snapshot_gen.py из GitHub API. Расхождение = перегенерация, не правка.

- `snapshot.json` — сырой фактический слепок 80 репо от 2026-11-21T19:41:37Z
- `СЧЁТЧИКИ.md` — итоги (коммиты, файлы, тесты, CI, вердикты) — из снапшота
- `СТАТУС.md` — вердикт по каждому репо: работает/прототип/статика — из фактов
- `../tools/snapshot_gen.py` — сборщик; офлайн-вселенная может пересобрать карту где угодно

Перегенерация (живой API — только по команде, токен в секретах CI):

    GH_TOKEN=<секрет> python3 tools/snapshot_gen.py --out snapshot/

Честные границы: вердикт «работает» = последний прогон CI зелёный И тесты
есть; деревья с усечением считаются по видимой части (список в СЧЁТЧИКИ.md);
числа витрины и карты (karta) при расхождении с этим файлом считаются
устаревшими — источник здесь.
